## KILDE / FAKTA

KDRS Query-dokumentasjonen inneholder blant annet Noark 5-arbeidsbeskrivelser, rapportmaler, loggmaler og XPath/XQuery-definisjoner.

Den siste kjente Noark 5 XPath-serien bygger på 2022-definisjonene, med en forbedring/fix av generiske tellinger i mai 2026.

U1 og U2 er videreutviklede analyseprofiler for henholdsvis samlet uttrekk og per arkivdel.

## VÅR VURDERING

KDRS Query-materialet er både historisk dokumentasjon og viktig kontrollgrunnlag for ny Python/lxml-implementasjon.

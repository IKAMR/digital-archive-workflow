# Noark 3 - standardspesifikasjon

**Kilde:** Riksarkivet, *NOARK-3: Standardsystem for EDB-basert
journalføring i statsforvaltningen*, samlet kravspesifikasjon 1994.
Dokumentet oppgir også **2. opplag, januar 1995**.

## Originaldokument

- [`spesifikasjoner/Noark-3 (1994).pdf`](spesifikasjoner/Noark-3%20%281994%29.pdf)
  - 144 sider
  - originalt filnavn fra brukerarkivet `noark.zip`

Dette er en historisk kilde til Noark 3. Begreper og krav må vurderes mot
faktisk Noark-versjon og kildegrunnlag, ikke overføres ukritisk til
Noark 4 eller Noark 5.

Se overordnet [`README.md`](../README.md) for rettighetsstatus og
[`SOURCE-MANIFEST.json`](../SOURCE-MANIFEST.json) for SHA-256.

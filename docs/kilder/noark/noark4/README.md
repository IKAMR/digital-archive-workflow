# Noark 4 / 4.1 - standardspesifikasjoner

Kilden består av to deler av Noark 4-rapporten, en kravtabelloversikt,
en feilrettingslogg og to dokumenter om endringer fra den trykte
1999-utgaven. Rapportene beskriver **Noark versjon 4.1**, med senere
justeringer. Del II oppgir oppdatert nettversjon **17.08.2005**.

## Originaldokumenter

| Fil | Funksjon |
| --- | --- |
| `Noark-4_del1.pdf` | Del I: funksjonsrettet beskrivelse og kravspesifikasjon |
| `Noark-4_del2.pdf` | Del II: tekniske spesifikasjoner |
| `N4 Feilrettingslogg for Noark-4 Del 1 og 2.pdf` | Feilrettinger / justeringer av spesifikasjonen |
| `N4_1 Kravtabellene.pdf` | Veiledning/oversikt knyttet til kravtabellene og kravnivåene |
| `N4_endringer_del1.pdf` | Endringer i del I mot trykt 1999-utgave |
| `N4_endringer_del2.pdf` | Endringer i del II mot trykt 1999-utgave |

Alle PDF-ene ligger i [`spesifikasjoner/`](spesifikasjoner/) med **uendrede filnavn**.

## Viktige tolkningsregler

- Endringsdokumenter og feilrettingslogg er selvstendige kilder og må
  vurderes sammen med hovedrapportene.
- Kravnivåer er relevante; krav som gjelder en utvidet funksjon er ikke
  automatisk obligatoriske for enhver Noark 4-installasjon.
- Versjon og faktisk anvendelse må dokumenteres ved vurdering av konkrete
  arkivuttrekk.
- Fagmodellen er ikke lik teknisk databasemapping for ePhorte, ESA,
  DocuLive eller andre leverandører.

# Noark 5 v2.0 – kildemateriale

Denne mappen inneholder referansefiler knyttet til **Noark 5 v2.0**, slik de foreligger i `IKAMR/digital-archive-workflow` per 2026-11-07. Materialet brukes til historisk kildekartlegging og versjonsspesifikke vurderinger. Det er ikke dokumentasjon av et konkret arkivuttrekk.

## Registrerte filer

### XML-skjemaer (`schemas/`)

- [`Noark-5_avlevering_arkiv_v_2_0.xsd`](schemas/Noark-5_avlevering_arkiv_v_2_0.xsd)
- [`Noark-5_avlevering_basismappe_v_2_0.xsd`](schemas/Noark-5_avlevering_basismappe_v_2_0.xsd)
- [`Noark-5_avlevering_endringslogg_v_2_0.xsd`](schemas/Noark-5_avlevering_endringslogg_v_2_0.xsd)
- [`Noark-5_avlevering_v_2_0.xsd`](schemas/Noark-5_avlevering_v_2_0.xsd)
- [`Noark-5_metadatakatalog_v_2_0.xsd`](schemas/Noark-5_metadatakatalog_v_2_0.xsd)

**Standard/vedlegg:** Ingen spesifikasjonsdokumenter er lagt inn i denne versjonsmappen.

## Kildebruk og status

- Bruk alltid riktig versjon ved kontroll og vurdering av et konkret uttrekk.
- Skille mellom normative krav i spesifikasjonen, tekniske XML-skjemaer og eventuelle eksempler.
- Ikke anta at filer fra ulike versjoner er utbyttbare fordi navnene er like.
- Opphav, offentliggjøringsrettigheter og SHA-256 for disse filene er **ikke ferdig dokumentert** i det eksisterende `SOURCE-MANIFEST.json`.
- Avklar utgave, kilde og publiseringsrett for dokumentene før de behandles som autoritative eller fritt redistribuerbare.

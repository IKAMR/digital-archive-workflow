# Arkade 5 – kildekartlegging

- https://arkade.arkivverket.no/
- https://github.com/nasjonalarkivet/arkade5

## KILDE / FAKTA

Arkade 5 er en sentral offentlig referanse for validering og analyse av arkivuttrekk, inkludert Noark 5.

## VÅR VURDERING

Arkade 5 skal brukes som sammenlignings- og referansekilde, men ikke som eneste premiss for ny rapportstruktur eller intern analysearkitektur.

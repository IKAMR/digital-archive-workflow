# U1 – samlet analyse av hele Noark 5-uttrekket

## KILDE / FAKTA

U1 er utviklet som en konsentrert og mer strukturert opptelling/analyse av hele Noark 5-uttrekket.

U1 bygger videre på historiske Noark-tester og XPath/XQuery-analyser, og er utviklet med gjennomgang av Noark 5 versjon 3.1, 4.0 og 5.0 som bakgrunn.

## VÅR VURDERING

U1 er først og fremst en logisk rapport-/analyseprofil. Underliggende beregninger bør splittes i små gjenbrukbare analysekomponenter.

## NY STANDARD / BESLUTTET

U1 brukes som profil for samlet Noark 5-innhold.

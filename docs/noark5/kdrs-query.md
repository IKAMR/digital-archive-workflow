# KDRS Query og XPath/XQuery

## KILDE / FAKTA

Offentlig repository:

- https://github.com/IKAMR/KDRS_Query
- https://github.com/IKAMR/KDRS_Query/tree/master/doc

KDRS Query-materialet inneholder historiske XPath/XQuery-definisjoner, Noark 5-dokumentasjon og senere U1/U2-oppsett.

Den siste kjente Noark 5 XPath-serien bygger på 2022-definisjonene, med en forbedring/fix av generiske tellinger i mai 2026.

## VÅR VURDERING

De konkrete spørringene er både teknisk implementasjon og historisk dokumentasjon av hvilke opplysninger man ønsket å hente ut.

Ved ny implementasjon bør faglig hensikt og forventet resultat dokumenteres uavhengig av XPath/XQuery-syntaksen.

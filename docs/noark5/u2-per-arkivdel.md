# U2 – analyse per arkivdel

## KILDE / FAKTA

U2 er utviklet for konsentrert analyse og opptelling per arkivdel.

## VÅR VURDERING

U2 gir et annet diagnostisk perspektiv enn bare totaler for hele uttrekket.

## NY STANDARD / BESLUTTET

U2 brukes som profil for analyse per arkivdel. Underliggende beregninger bør så langt som mulig deles med U1 og andre profiler.

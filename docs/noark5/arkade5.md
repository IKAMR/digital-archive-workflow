# Arkade 5

## KILDE / FAKTA

Arkade 5 gjennomfører en rekke Noark 5-tester og kan produsere testresultater og rapporter i flere presentasjonsformater.

Offentlige kilder:

- https://arkade.arkivverket.no/
- https://github.com/nasjonalarkivet/arkade5
- https://github.com/nasjonalarkivet/arkade5-dokumentasjon

## VÅR VURDERING

Arkade 5 er en viktig referanseimplementasjon og sammenligningskilde, men skal ikke behandles som eneste fasit for hvordan den nye arbeidsmodellen eller rapportstrukturen må organiseres.

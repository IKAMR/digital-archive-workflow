# Referanser og eksterne kilder

Denne listen er en første, kuratert oversikt over eksterne kilder som er relevante for `digital-archive-workflow`.

## Nasjonalarkivet / Arkivverket

### Arkade 5

- https://arkade.arkivverket.no/
- https://github.com/nasjonalarkivet/arkade5
- https://github.com/nasjonalarkivet/arkade5-dokumentasjon

**Relevans:** validering, analyse og rapportering av arkivuttrekk, særlig Noark 5.

### Noark 5 og skjema

- https://github.com/nasjonalarkivet/noark5-standard
- https://github.com/nasjonalarkivet/schemas

**Relevans:** faglig og teknisk grunnlag for Noark 5-kontroller, XML-validering og strukturforståelse.

## KDRS Prosesser og rutiner

- https://www.kdrs.no/kdrs-prosesser
- https://prosjekt.kdrs.no/ProsessDigitaltDepot/V1.0/ProsessDigitaltDepot.htm
- https://prosjekt.kdrs.no/ProsessDigitaltDepot/V2.02/ProsessDigitaltDepot.htm

**Relevans:** prosessgrunnlag for digitalt depot.

## IKAMR

### KDRS Query

- https://github.com/IKAMR/KDRS_Query
- https://github.com/IKAMR/KDRS_Query/tree/master/doc

**Relevans:** historisk og praktisk analyse- og kontrollgrunnlag, XPath/XQuery-baserte Noark 5-analyser og U1/U2.

### KDRS Metadata

- https://github.com/IKAMR/KDRS_Metadata

### Digitalt depot prosesser

- https://github.com/IKAMR/digitalt-depot-prosesser

**Relevans:** IKAMRs implementering av KDRS Prosesser og rutiner, med tilhørende operativ dokumentasjon, test- og valideringsopplegg, uttrekksveiledning, depotlogger og standardiserte arbeids- og mappestrukturer.

## SIARD og arbeidsflyt

- https://github.com/smult/SIARD-Workflow-Manager

**Relevans:** praktisk arbeidsflyt for SIARD og referanse for generiske prinsipper om profiler, logging, pakking og arbeidssteg.

# Historikk

## Foreløpig utviklingslinje for Noark 5-validering

Arbeidet kan foreløpig spores gjennom flere lag:

1. opprinnelige Noark 5-tester utviklet med utgangspunkt i Arkivverkets testopplegg
2. rutiner og arbeidsbeskrivelser for test og godkjenning
3. konkrete XPath/XQuery- og SQL-baserte analyser
4. KDRS Query som automatisering av deler av testarbeidet
5. Arkade 5 med implementerte Noark 5-tester
6. videreutviklede analyser strukturert som U1 for hele uttrekket og U2 per arkivdel
7. forbedring av generiske tellinger i XPath-definisjonene i mai 2026
8. arbeid med en ny, mer generell og automatisert arbeidsmodell

## Viktig

Dette er en historisk utviklingslinje, ikke en påstand om at alle verktøy eller testsett er identiske. Senere dokumentasjon skal kartlegge hvilke faglige kontroller som faktisk overlapper, hvilke som er forskjellige, og hvilke nye analyser som er kommet til.

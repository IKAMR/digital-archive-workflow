# Kilder og status

## Kildekategorier

Foreløpig inngår blant annet:

- Noark-standarder og tilhørende spesifikasjoner
- Nasjonalarkivets/Arkivverkets historiske og nåværende test- og verktøykilder
- KDRS Prosesser og rutiner
- IKAMR-implementasjoner og arbeidsdokumentasjon
- Arkade 5
- KDRS Query
- U1- og U2-analyser
- praktiske erfaringer fra mottak, testing, godkjenning, bevaring og innsyn
- gjeldende lover, forskrifter og andre normative kilder

## Kildestatus

En kilde kan være historisk, gjeldende, erstattet, under utvikling eller intern/upublisert. Dette skal fremgå når vi bruker den.

## Interne kilder

Interne eller upubliserte dokumenter skal ikke legges i dette åpne repoet.

## Verifisering

Påstander om gjeldende lov, forskrift eller annen normativ status skal verifiseres mot autoritativ kilde før de dokumenteres som gjeldende krav.

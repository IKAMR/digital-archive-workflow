# Logging og sporbarhet

Intern logg/hendelsesdata skal være datagrunnlaget. PREMIS, CSV, JSON og andre formater er representasjoner av relevante deler av samme grunnlag.

Det skal være mulig å dokumentere jobb, uttrekk, bruker/agent, operasjon, tidspunkt, resultat, avvik, måledata og brukt profil/definisjon.
